# Electives
ISA submission deadline is 30th may

# Rules
- 3-week rule: for course registration before either 3 weeks of the semester go exam/project has started. (unless course description says otherwise)

- The Master project can only start after 60 ECTS has passed
- The Bachelor project can only start after 120 ECTS has passed

# Projects
Project descriptions deadline is 1 week into the semester
It is strongly encouraged to submit at least 1 week before semester start, for review and approval

Specialized projects can be individual or in groups of up to 4.
